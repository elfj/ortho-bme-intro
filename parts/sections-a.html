四個名詞，一層包一層AI ⊃ ML ⊃ DL ⊃ Generative AI

新聞把它們混著用，但其實是由大到小的包含關係——越裡層，越不需要人教規則。

AI · 讓電腦做需要智慧的事
  • 包含人寫規則的系統。例：依 Ottawa ankle rules 跳出「建議照 X 光」的提示
ML · 從資料自己學規則
  • 例：用年齡、骨密度、跌倒史等表格資料預測骨折風險
DL · 多層神經網路，直接看原始影像
  • 例：輸入整張 X 光，輸出「骨折機率」與位置（Part 2 的主角）
生成式 AI · 產生新內容
  • 例：LLM 起草手術說明與衛教文字（Part 3 的主角）
Bottom line
今天聚焦最裡面兩層：深度學習（會看片）與生成式 AI（會寫字）。

傳統程式 vs 機器學習Who Writes the Rules?

關鍵差別只有一個：規則是人寫的，還是從資料學出來的。

✎傳統程式
規則+資料→答案
  • 人先寫好規則：「皮質線中斷超過 X mm → 骨折」
  • 問題：骨折型態太多，規則寫不完；影像品質一變就失靈
像背一本「判讀規則手冊」。
⚙機器學習
資料+答案（標註）→規則
  • 給電腦十幾萬張醫師已標註的 X 光（骨折 / 無骨折）
  • 電腦自己找出區分兩者的規則，再用在沒看過的新影像
像住院醫師看了上萬張片，被主治一張張糾正。
Bottom line
答案從標註來，所以標註的品質決定模型的上限——Lindsey 2018 找了 18 位資深骨科醫師來標註，就是這個原因。

資料來源：Lindsey R et al., PNAS 2018;115(45):11591–6。流程圖本演講自製。

神經網路怎麼「學」？The Training Loop

訓練就是一個迴圈：猜 → 對答案 → 修正，重複幾十萬次，直到猜得夠準。

01 · 預測

輸入一張 X 光，網路先猜

剛開始幾乎亂猜：「骨折機率 0.30」

02 · 對答案

和醫師標註比對

標註是「骨折」(= 1)，差了 0.70——這個差距叫誤差（loss）

03 · 修正

微調數百萬個權重

每個權重往「誤差變小」的方向挪一點點，然後換下一張

你已經
懂的類比
訓練集 = 練習題拿來學、可以反覆看
測試集 = 期末考完全沒看過的新影像，才算真本事
過擬合 = 背考古題練習題全對，換一間醫院就不會
Bottom line
模型沒有「理解」骨折，只是把誤差壓到最小——資料裡有什麼偏差，它就學到什麼偏差（Part 4 再談）。

卷積神經網路怎麼「看」影像？CNN · Edges → Textures → Shapes

和你生理學學過的視覺路徑很像：淺層看邊緣，深層看形狀，最後組合成判斷。

三句話
記住
卷積 = 拿小模板滑過整張圖每個模板專找一種花樣（邊、角、紋路）
特徵是學出來的沒有人告訴它「骨小樑長什麼樣」

影像 AI 的三種任務Classification · Detection · Segmentation

先問清楚 AI 輸出的是什麼：一個標籤、一個框，還是一張逐像素的輪廓？

01 · 分類Classification

這張片「是什麼」？

輸出：標籤＋機率
有無骨折；膝關節 OA 嚴重度 Kellgren–Lawrence 0–4 級（Tiulpin 2018）
對應臨床：篩檢、分流、分級
02 · 偵測Detection

問題「在哪裡」？

輸出：位置框＋機率
在 X 光上框出骨折位置，提醒醫師回頭看那一區
對應臨床：急診判讀輔助（第二雙眼）
03 · 分割Segmentation

精確「輪廓」在哪？

輸出：逐像素遮罩（mask）
描出椎體、骨骼輪廓 → 3D 規劃與導航的基礎；MedSAM 以超過一百萬組影像–遮罩對訓練
對應臨床：術前規劃、量測、導航
Bottom line
後面幾週的脊椎生物力學、導航手術，第一步幾乎都是「分割」。

資料來源：Tiulpin A et al., Sci Rep 2018;8:1727；Ma J et al., Nat Commun 2024;15:654（MedSAM）。圖示本演講自製。

模型輸出是機率，閾值是你決定的Threshold = Screening Cut-off

AI 給的是 0 到 1 的分數；切在哪裡才決定陽性 / 陰性——和篩檢試驗的 cut-off 完全相同。
